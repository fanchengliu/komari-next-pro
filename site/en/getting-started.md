# Get started

You need an existing Komari installation. The current compatibility baseline is Komari 1.5.0.

1. Open [GitHub Releases](https://github.com/fanchengliu/komari-next-pro/releases/latest).
2. Download the package ending in **`-theme.zip`**.
3. Upload it in Komari's theme manager and select **Komari Next Pro**.
4. Return to the home page and complete the setup wizard.

The source ZIP and GitHub's automatically generated source archives are not installable themes. The companion ZIP is optional.

## Upgrading

The public name is Komari Next Pro; the technical theme ID remains `komari-ds` for compatibility. Existing DS settings and companion routes are preserved. Next Pro 2.x users should keep their old theme, configuration and services while switching to the independently implemented 3.x version.

Back up personal media before replacing packaged defaults. Store personal backgrounds in an independent media library if you want to retain them across theme updates.

After installation, force-refresh the browser if old branding or styles remain. To roll back, reinstall your retained theme package or select the previous theme.
