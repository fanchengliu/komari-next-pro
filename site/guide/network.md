# 网络历史与节点对比

## 首页延迟和丢包

节点卡片中的时间格表示所选历史窗口。悬停可查看时间段和统计值，点击可展开完整曲线。

每张卡片会显示监测范围。自动模式优先当前节点的 TCP 任务；没有 TCP 任务时使用已观测线路。也可在布局与网络中改为全部线路或自定义任务。

::: tip 1 ms 不一定是错误
同机房或附近目标可能确实只有约 1 ms。先检查所选任务、目标与统计范围。“最近接收 1 秒”是上报接收时间提示，不参与延迟计算。
:::

## 网络总览

选择节点、监测任务和相同的时间窗口，再比较平均延迟、P95 和丢包。支持晚高峰时段、自定义时间以及图表框选。

比较两台节点时，应尽量选择相同运营商与相近地区的目标；不同探测目标的数字不能直接解释为机器本身的优劣。

## 节点对比

通过节点卡片的“加入对比”选择最多四台节点。对比基础信息、资源规模与网络记录。界面只展示当前身份可以访问的节点。

历史数据能看到多远，取决于 Komari 后端的保留策略。缺失时段和离线节点不会生成虚构样本。
