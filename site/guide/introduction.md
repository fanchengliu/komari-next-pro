# 项目介绍

Komari Next Pro 是为 Komari 编写的主题。3.0 使用独立的 React + TypeScript 实现，提供节点概览、网络历史、节点对比、全球节点和个性化外观。

## 主题和 Komari 的关系

Komari 负责接收 Agent 上报、保存数据和提供 API；主题负责把这些信息展示出来。使用前需要已有可正常运行的 Komari 服务。

本项目的文档站仅用于介绍和使用说明，不会连接或展示你的生产节点。

## 只装主题能用什么

- 节点概览、搜索、分组、卡片与紧凑布局。
- 服务器详情、资源历史、延迟和丢包曲线。
- 最多四台节点的基础信息与网络对比。
- 可旋转的全球节点地球。
- 资产、到期时间线、流量统计和世界时钟。
- 配色、透明度、本机背景及五种界面语言。

服务器媒体库、链接下载和手动节点任务使用[可选扩展服务](./extension)。

## 数据边界

IP 参考评分是可展开依据的规则估算，不代表真实信誉检测或风险概率。流媒体 HTTP 可达也不代表账号或地区已完整解锁。缺少历史或监测数据时，界面会保留未知，不把缺失数据填成零。
