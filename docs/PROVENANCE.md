# Code, data and artwork provenance

Komari Next Pro is the public continuation of the independently authored komari-ds implementation. Its React components, data adapters, globe renderer, tests and companion service are maintained in this repository. Legacy Komari Next Pro was based on komari-next; that lineage and its original copyright notice remain in repository history and LICENSE. Orbit does not build or load the legacy theme bundle.

The technical theme ID `komari-ds`, browser storage keys and companion API prefix remain for compatibility. The public name is Komari Next Pro.

## Artwork

- `apps/theme/public/media/logo.svg`: newly authored vector orbit mark; PNG generated by scripts/render-brand.mjs.
- `background-poster.png`: new artwork generated with the built-in image_gen tool. No user image was used as input. The prompt is recorded in docs/brand/PROMPT.md.
- `background.mp4`: original procedural canvas orbit loop generated by scripts/render-brand.mjs.
- `docs/brand/cover.png`: typeset brand cover composed from the new artwork and vector mark.
- `docs/images/*`: screenshots of the real production build against local, synthetic demonstration APIs. Example IPs use documentation ranges. They are not customer or production monitoring results.

These new project assets are distributed with this repository under its MIT terms, subject to applicable third-party rights. This is not a trademark clearance claim. No personal-site anime media, personal Logo, live-node export or private deployment transcript is part of this public tree.

## Data and dependencies

Map databases retain ISC/public-domain/ODbL terms documented in GEODATA.md and docs/licenses. Flags are from flag-icons; icons, fonts supplied by the host and npm dependencies retain their licenses in THIRD_PARTY_NOTICES.md.

Runtime APIs are Komari's documented interfaces and the optional configured providers. IP reference scores are explicitly labeled deterministic heuristics, not measured reputation. Native provider flags are kept separate. No hashing or random score perturbation is used.
