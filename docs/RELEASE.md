# Komari Next Pro 3.0.2

- 首页节点卡片不再单独显示“TCP 线路 · 6 / 1 h”一行；监测任务和统计时段保留在延迟、丢包按钮的悬停说明中，点击仍可查看完整详情。
- 布局预设改为紧凑的选项和真实节点预览。桌面、手机分别设置，清晰区分“预览”和“已应用”，点击应用后才保存。
- 修复切换设备预览后可能将布局应用到错误设备的问题，适配窄屏、深浅色和键盘操作。
- 包含此前发布到主分支的首页筛选栏悬停、聚焦和分组选中反馈。
- 补充布局说明的多语言翻译与浏览器回归检查。

## 下载与升级

- `komari-next-pro-3.0.2-theme.zip`：在 Komari 主题管理中导入。
- `komari-next-pro-3.0.2-source.zip`：完整可修改源码及构建说明。
- `komari-next-pro-3.0.2-extension.zip`：可选配套服务安装包。
- `SHA256SUMS` 与 `manifest.json`：文件校验值。

本次更新集中在主题界面，延迟与丢包的计算和任务选择逻辑保持兼容。已有 3.0.1 扩展服务无需升级或重启，扩展 API 版本保持 3.0.1；主题技术安装标识仍为 `komari-ds`。

导入新版主题后重新打开页面即可。包中使用项目的公开默认素材，不包含私人壁纸、服务器凭据或监控数据。
