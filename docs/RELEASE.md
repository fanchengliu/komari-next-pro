# Komari Next Pro 3.0.1

- 页脚显示 Komari Next Pro · Powered by Komari Monitor.，新增 GitHub 图标并在新标签页打开仓库。
- 新增简洁的中英文文档站：首页、安装、功能指南、配套服务、FAQ、开发与社区；支持本地搜索、深浅色和手机导航。
- 分开主题与官网构建，提供 Vercel 根目录配置及旧 theme/public 静态发布路径的兼容配置。
- README 末尾新增致谢。

主题包、源码包和扩展包分别为 -theme.zip、-source.zip、-extension.zip。本轮主题端改动兼容现有扩展，无需为页脚更新重启配套服务。技术安装标识仍为 komari-ds。

旧页脚需安装新版主题并刷新后更新。网站部署状态以 Vercel 新提交的 Preview/Production 记录为准，旧失败记录保留。
