# 数据与展示规则

Komari 1.5.0 的 RPC 使用请求/响应。单标签页只创建一个客户端；状态 5 秒、节点与站点配置 60 秒，隐藏标签页停止周期刷新。查询缓存包含访客/账号标识，登录退出清理旧身份数据；切换图表时丢弃旧请求结果。

节点状态包含真实零、未知、离线和失联保留值。服务器请求失败时显示错误并保留上次成功的状态，不把整个列表改成离线。节点名称以文本渲染，不执行 HTML。

## 流量

原生 `public:queryMetrics` 读取 `traffic.up/down` (sum) 与 `net.total.up/down` (last)。主题不读内部 SQL 表。原生接口已选择聚合粒度，因此主题不会把不同 SQL rollup 表相加。

每个非零增量桶采用增量；增量为零的旧迁移桶可由相邻累计计数估算。重置时，新的累计值不超过 64 GiB 才作为重置后增量；巨大向下跳变不计入。重复时间戳去重，乱序排序。首个累计点之前的流量不可恢复，不填造数据。

存在恢复计数、粗聚合桶或缺少边界数据时标记估算；未知方向不变成零。历史数据被删除后，重写无法恢复原始精度。今日/昨日采用 America/New_York 的日界线，包括 23/25 小时夏令时；7/30 天为滚动范围。界面显示时区独立设置。

“月度”卡片遵循现有额度展示：以当前累计上下行按 sum/max/min/up/down 模式计算，非独立的自然月账单。上行/下行方向始终独立。

## 资产与到期

资产购买费用按节点 price 和主题配置汇率换算；月均/年化费用另按 billing_cycle 折算。负价/零价免费节点不计费，缺少汇率不默认为人民币。默认汇率是可编辑配置值，不声称实时行情。长期节点在卡片显示天数，在时间线显示长期，按用户要求保留差异。

访客资产/到期弹窗保留空列表呈现；访客流量弹窗保留登录提示；IP、网络归属和解锁数据保留掩码。授权在服务端检验，前端掩码不是访问控制的替代。

心情/等级是独立展示模型，不作为实际健康诊断。等级按运行时长 7/30/90/180/365 天分档；心情根据在线状态、CPU 与内存负载分档。10/51/98 天等已知参考样例的等级一致；未从旧源码提取计算函数。延迟和丢包共用同一 CSS Grid 行，月度内容不折行挤压后续位置。

IP 版本徽标仅在官方接口提供对应地址时展示，访客接口未返回能力字段时不猜测。源站本机地址和出口 IP 元信息分别处理；质量数据只展示有来源的字段。
