Features ​

Layout and appearance ​

Use daily cards, compact inspection tables or mobile layouts. The palette button opens theme settings. Card transparency changes the background alpha while text and charts remain opaque. Personal preferences are saved in your browser; administrators can save site defaults.

Image/video backgrounds support ordered, random and hold modes. Server-side upload and URL import require the companion service. A public media URL is required; share pages and authenticated downloads are not direct media links.

Network history and comparisons ​

Hover or select a history cell to inspect latency and packet loss. Compare up to four nodes with an explicit common time window. Automatic home summaries prefer assigned TCP monitoring tasks; the selected scope is shown on each card.

Nearby targets can genuinely return 1 ms. The “last received” indicator is report age, not a latency measurement.

Global globe ​

Drag the globe, use arrow keys, or click a flag to select a node in the adjacent list. Coordinates are approximate region centers, not precise data-center locations. The home regions card opens the globe in a modal.

Reports ​

View free and paid assets, expiry timelines and traffic totals. Dates more than ten years ahead display as long-term. Exchange rates are the latest published reference values with source dates and cache status. They are not live trading quotes.

History coverage and precision depend on your Komari backend. Missing data is not converted into invented samples or zero traffic.
