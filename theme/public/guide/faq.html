常见问题 ​

为什么页脚还是 komari-ds？ ​

通常是仍在使用旧主题包或缓存。导入新的 Komari Next Pro 主题包后强制刷新；必要时清理旧站点 Service Worker。技术安装标识保留为 komari-ds，但公开显示名称和页脚使用 Komari Next Pro。

为什么 /admin 仍显示首页？ ​

后台和终端应由 Komari 原生页面提供。检查旧 Service Worker 和反向代理是否把这些地址缓存或回退为主题首页。不要用文档站或主题静态页接管 /admin。

IP 质量为什么有“估算”字样？ ​

参考模式是基于资料完整度和网络分类规则的估算，没有随机扰动，不是真实信誉检测或风险概率。真实数据源指标在单独页签中展示，未配置或未知时会明确标注。

检测显示“部分完成”是什么意思？ ​

IPv4、IPv6 和质量查询分别执行。一个协议或数据源失败时，已经取得的结果会保留，同时显示失败或未配置原因。重新测试不会保证外部服务、DNS 或节点网络一定可用。

为什么流媒体“可达”却不能使用？ ​

HTTP 响应不能证明账号、地区、订阅或特定内容已解锁。面板保留实际响应证据，不把 HTTP 200 直接标成完全解锁。

背景链接为什么无法下载？ ​

确认是公开的图片或视频直链，并已启用配套扩展。登录下载页、网页分享链接、内网地址、超时或超过文件限制的媒体不会被导入。

GitHub Deployments 出现红叉代表什么？ ​

它表示托管平台的一次部署失败，和主题 Release 的单元测试并非同一个状态。应查看该次部署日志、根目录、构建命令及输出目录。旧失败记录是历史记录，后续成功部署不会把它们伪装为成功。

可以直接把监控主题部署到 Vercel 当官网吗？ ​

本仓库的 Vercel 入口是文档站。监控主题需要安装在 Komari 中，才能正常读取节点和 API；文档站是静态介绍页面，不连接生产监控数据。
