# Theme Source Notes

This `theme/` directory contains the current Komari Liu theme source and generated Komari upload artifact.

- `komari-theme.json` — Komari theme metadata/configuration.
- `public/` — generated theme artifact used by Komari.
- `src/` — source files used to generate `public/`.

Root repository README/docs are intentionally preserved from the existing `fanchengliu/komari-next-pro` repository.
