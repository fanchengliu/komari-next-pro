# Security

Do not put secrets, private-node exports or production databases in public issues. For a sensitive report, use GitHub's private vulnerability reporting feature when enabled; otherwise open an issue requesting a private contact without publishing exploit details or credentials.

The companion service validates Komari login sessions, Origin and CSRF on writes. Probes are fixed commands triggered explicitly for a visible node. Media imports reject private destinations and revalidate redirects. These controls still require correct reverse-proxy and Agent configuration.

Frontend masking or disabled keyboard shortcuts are presentation preferences, not access control. Use Komari's backend visibility settings to protect data. Keep provider keys only in the server environment.
