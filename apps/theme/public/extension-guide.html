KOMARI NEXT PRO / COMPANION SERVICE

扩展服务接入

背景下载、媒体上传和节点检测由同服务器上的独立配套服务提供。主题设置中的“扩展服务”可查看连接状态。

1. 安装配套服务

将与主题一同提供的 komari-next-pro-3.0.0-extension.zip 解压到服务器上的独立目录。需要 Node.js 24.15 或更高的 24 / 26 版本；视频转码另需 FFmpeg。使用扩展包内的 deploy/komari-ds-extension.service 持续运行，Docker 方案见 deploy/Dockerfile。

npm ci --ignore-scripts --no-audit --no-fund
DS_KOMARI_ORIGIN=http://127.0.0.1:25774
DS_PUBLIC_ORIGIN=https://你的监控域名
DS_DATA_DIR=/var/lib/komari-ds
DS_BIND=127.0.0.1
DS_PORT=5175
DS_ENABLE_JOBS=true
DS_FFMPEG=/usr/bin/ffmpeg

这些变量写入服务环境文件；启动命令为 node --import tsx apps/extension/src/main.ts。运行账号需能写入独立数据目录。

2. 添加同域代理

把以下 location 加到现有监控域名的 Nginx server 块内，保留已有后台、终端与 Worker 配置。

location ^~ /komari-ds-api/ {
    proxy_pass http://127.0.0.1:5175;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 101m;
    proxy_read_timeout 310s;
    proxy_request_buffering off;
}

执行 nginx -t 通过后再 reload。访问 /komari-ds-api/v1/capabilities 应返回版本及 media、ip、unlock、services 能力，再回主题点“重新检查连接”。

3. 使用背景与节点检测

登录后可直接上传图片/视频，或输入公开 HTTP(S) 直链下载到服务器媒体库，再保存播放列表。支持顺序轮播、随机、保持当前背景以及视频完整播放/固定时长。最大单文件 100 MiB，下载超时 45 秒；不支持网页分享链接、需要登录的下载链接或内网下载地址。

节点检测使用现有 Komari Agent，不需要逐节点安装主题扩展。应在 Komari 中允许对应 Agent 执行任务；按钮点击后才执行。若站点任务接口要求 API Key，可设置 DS_KOMARI_API_KEY，密钥只保存在服务端。

IP 归属通过节点出口查询；配置 DS_IPAPI_KEY 可增加有来源的 IP 质量数据。流媒体面板展示实际 HTTP 响应证据，可达不代表账号或地区已解锁。

免 Key 参考估算

2.2.2 主题默认用已取得的 IP 归属资料生成规则估算，可展开每项计算依据，不增加外部请求、不自动执行节点任务。它不是实际信誉检测或风险概率；真实的 VPN、代理、Tor 等标记保留在“数据源指标”页签。已有 2.2.1 扩展可继续使用，无需为本次外观更新重启服务。

IP 质量数据源

在 ipapi.is 官方网站创建账号获取 API Key，在服务器扩展环境文件中配置 DS_IPAPI_KEY，重启独立扩展后手动重新测试。密钥只保存在服务器，不能填入主题公开配置。免费账号额度和字段以 官方文档 为准。

面板显示机房、VPN、代理、Tor、滥用记录及数据源实际提供的网段滥用比例。未配置、限流、失败和未知会分别显示；网段比例不是单 IP 的风险概率。

2.2.1 将 IPv4、IPv6 与质量查询分开报告。旧缓存不会自动执行新检测，点击“重新测试”获取新版结果。

自动汇率

2.2 服务提供 /komari-ds-api/v1/exchange-rates，自动获取 Frankfurter 最新公布参考汇率，缓存一小时并保留失败回退数据；无需填写汇率或 API Key。数据日期和来源在主题设置及资产统计中显示，非秒级交易报价。

保留原服务与回退

此服务不读取旧主题的内部数据库。旧服务、媒体和主题包应保留；媒体可手动复制迁移。回退时停止新增服务并移除专用代理 location 即可，媒体目录无需删除。扩展包附有完整部署、数据迁移与权限说明。
